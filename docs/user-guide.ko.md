# YouTube Live Translator 사용 가이드

[한국어](user-guide.ko.md) · [English](user-guide.en.md) · [日本語](user-guide.ja.md) · [README](../README.md)

> 이 확장 프로그램은 독립적으로 개발된 비공식 프로젝트입니다. YouTube 또는 네이버 치지직(CHZZK)의 공식 서비스가 아니며, 두 서비스의 운영사와 제휴 관계가 없고 공식 승인이나 보증을 받지 않았습니다.

YouTube와 치지직 영상 위에 번역 자막을 표시하는 Chrome 확장 프로그램입니다. **처음이라면 제작자가 올린 자막이 있는 YouTube 영상부터** 테스트하세요. 원문 자막을 그대로 받아 번역하므로 음성 인식(STT)을 설치하거나 켤 필요가 없습니다.

## 1. 준비물

- **컴퓨터:** Windows 또는 macOS 14 이상 Apple Silicon Mac(M 시리즈). Intel Mac, 휴대폰 앱·브라우저는 지원하지 않습니다.
- **프로그램:** 데스크톱 Chrome 116 이상, Git, Node.js 22.18 이상(24 권장, npm 포함).
- **첫 테스트:** OpenAI 또는 호환 제공자의 API 키와 번역 모델 ID. API 사용 권한과 요금은 제공자 계정에서 확인합니다. 로컬 번역은 [고급 설정 가이드](advanced-guide.ko.md)를 참고하세요.

대상은 YouTube 영상·라이브와 치지직 라이브·다시보기입니다. 다른 사이트나 로컬 영상 파일은 지원하지 않습니다.

## 2. 설치

Windows PowerShell 또는 macOS 터미널에서 아래 명령을 순서대로 실행합니다.

```bash
git clone https://github.com/ljwoo8942/youtube-live-translator.git
cd youtube-live-translator
npm ci
npm run build
```

1. Chrome 주소창에서 `chrome://extensions`를 엽니다.
2. **개발자 모드**를 켜고 **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
3. 방금 내려받은 `youtube-live-translator` 폴더 안의 **`dist`**를 선택합니다. 프로젝트 전체 폴더가 아닙니다.
4. Chrome 툴바의 퍼즐 아이콘에서 **YouTube Live Translator**를 찾습니다. 필요하면 고정해 두세요.

## 3. 첫 번역: YouTube 공식 자막

1. YouTube에서 제작자가 넣은 자막이 있는 영상을 엽니다. 플레이어의 **설정 → 자막**에서 `영어`나 `일본어`처럼 제작자가 제공한 원문 트랙을 선택합니다. `자동 생성`이나 `자동 번역`만 있는 영상은 첫 테스트에는 적합하지 않습니다.
2. 확장 프로그램 팝업에서 **전체 설정**을 엽니다. **기본 동작**에서 **입력 방식**은 **선택한 공식 자막만 사용 - STT/자동 자막 무시**, **번역 provider**는 **AI API**를 고릅니다. **목표 언어**에 한국어는 `ko`, 영어는 `en`, 일본어는 `ja`를 입력합니다.
3. **AI API**에서 번역 연결 정보를 입력합니다. 아래는 OpenAI 공식 API 예시입니다.

   | 화면 항목 | 입력값 |
   | --- | --- |
   | **API 프리셋** | **OpenAI 공식** 선택 후 **프리셋 적용** |
   | **Base URL** | `https://api.openai.com/v1` |
   | **API 키** | 본인의 API 키 |
   | **모델** | 예: `gpt-4o-mini`. 계정에서 사용 가능한 번역 모델 ID |
   | **인증 방식** | `Authorization: Bearer` |
   | **엔드포인트** | `/chat/completions` |

   다른 호환 API는 **직접 입력**을 선택하고 제공자가 지정한 Base URL, 키, 모델, 인증 방식 및 엔드포인트를 사용합니다. **모델 목록 불러오기**가 성공하면 **불러온 모델**에서 모델을 선택할 수도 있습니다.
4. **현재 설정 연결 테스트**를 누릅니다. 외부 서버 접근 권한 창이 나오면 설정한 제공자 주소인지 확인한 뒤 허용합니다. 통과하면 **설정 저장**을 누릅니다. 연결 테스트만으로는 설정을 저장하지 않습니다.
5. 영상 탭의 팝업에서 **켜기**가 선택되어 있는지 확인합니다. 바꿨다면 **저장**을 누르고 영상을 재생합니다. 재생 화면 위에 목표 언어 자막이 나오면 성공입니다. **음성 시작**은 누르지 않습니다.

## 4. 치지직·공식 자막 없는 YouTube: 음성 자막

음성 자막은 **STT로 탭 소리를 글자로 바꾼 뒤** 그 글을 번역합니다. API 프리셋을 사용하면 로컬 음성 인식 서버를 설치하지 않아도 됩니다.

1. **전체 설정 → API STT**에서 **API 키로 음성 자막 프리셋**을 누릅니다. OpenAI 공식 STT 기본값은 Base URL `https://api.openai.com/v1`, 모델 `gpt-4o-mini-transcribe`, 엔드포인트 `/audio/transcriptions`, 인증 방식 `Authorization: Bearer`입니다.
2. 번역에는 **AI API → API 키**를, 음성 인식에 별도 키가 필요하면 **API STT → API 키**를 입력합니다. STT 키를 비워 두면 **AI API** 키를 재사용하므로, 그 키가 STT 서버에서도 유효할 때만 비워 두세요. 번역과 STT 제공자가 다르면 프리셋 적용 뒤 각각의 주소·모델·인증 방식과 두 API 키를 확인하고, 각 제공자에 맞는 키를 직접 입력하세요.
3. **API STT + 번역 연결 테스트**를 누르고 통과하면 **설정 저장**을 누릅니다.
4. 치지직 본편이나 자막 없는 YouTube 영상이 실제로 재생되는 탭에서 팝업의 **음성 시작**을 누릅니다. Chrome이 탭 캡처 권한을 요청하면 대상 탭을 확인하고 허용합니다. 마치면 **음성 중지**를 누릅니다.
5. 공식 자막 번역으로 돌아가려면 **입력 방식**을 다시 **선택한 공식 자막만 사용 - STT/자동 자막 무시**로 저장합니다. YouTube에서 **음성 시작**을 누르면 입력 방식이 `음성만`으로 바뀝니다.

**대안: 내 컴퓨터에서 음성 인식.** [uv](https://docs.astral.sh/uv/getting-started/installation/) 설치 후 프로젝트 폴더에서 `npm run stt:setup`, `npm run stt:start`를 실행하고 터미널을 열어 둡니다. **전체 설정**의 **로컬 STT + 번역 API 프리셋**을 적용한 뒤 **로컬 STT + 번역 연결 테스트 → 설정 저장**을 진행합니다. 영상에서 **음성 시작**을 누르는 것은 동일합니다. 이 조합은 음성 인식만 로컬이고 번역은 API로 보냅니다. Qwen, 로컬 번역, 팝업 서버 제어는 [고급 설정 가이드](advanced-guide.ko.md)를 참고하세요.

자동 실행을 사용하려면 Native Messaging 호스트를 등록하고 모델을 준비하세요. 기본 주소를 사용하면 영상 팝업의 **음성 시작**이 서버와 음성 자막을 함께 시작합니다. 처음 표시되는 Chrome 권한은 확인 후 허용하세요. [자동 실행 설정](advanced-guide.ko.md#확장-팝업에서-로컬-stt-서버-시작중지)

Qwen 또는 Whisper로 첫 자막을 앞당기려면 **전체 설정**에서 **로컬 STT WebSocket 스트리밍 사용**을 켜고 저장합니다. 영상 탭에서 **음성 시작**을 누르면 일반 음성의 중간 인식 결과부터 LM Studio 또는 Ollama로 번역할 수 있습니다. **노래/가사** 모드는 확정된 인식 결과부터 표시합니다.

Gemma 4로 번역을 로컬에서 처리하는 방법과 빠른 일본어 노래에서 검증한 14초 HTTP 설정은 설정 가이드를 참고하세요. [LM Studio 설정 가이드](lm-studio-settings.md)

## 5. 업데이트

프로젝트 폴더에서 아래 명령을 실행합니다. 곡 교정 사전을 쓰고 있다면 먼저 JSON으로 백업하세요.

```bash
git pull
npm ci
npm run build
```

`chrome://extensions`에서 확장 프로그램의 **새로고침**을 누른 다음, **이미 열려 있던 YouTube·치지직 영상 탭도 새로고침**합니다. 로컬 STT를 사용한다면 기존 서버를 종료하고 `npm run stt:setup` 후 `npm run stt:start`로 다시 시작합니다.

## 6. 곡 교정 사전과 백업

팝업의 **교정 사전**을 열고 **새 곡**에서 곡 이름과 가수, 원문 가사, 교정 번역을 입력한 뒤 **저장**합니다. 일괄 편집을 사용했다면 **일괄 반영** 후 저장합니다. 적용하려면 **교정 적용**이 켜져 있는지 확인하세요.

- **백업:** 저장을 마친 뒤 **내보내기**를 누르면 JSON으로 저장됩니다. 저장하지 않은 편집과 전체 **교정 적용** 스위치, API 키·설정은 들어가지 않습니다.
- **JSON 복원:** **가져오기**로 JSON을 선택하고 확인하면 현재 Chrome 프로필에 저장된 곡 목록 **전체를 교체**합니다. 합치는 기능이 아니며, 빈 목록을 가져오면 기존 곡이 모두 사라집니다. 양쪽에 곡이 있다면 각 프로필을 따로 백업하고 중복 곡·ID를 정리한 뒤 진행하세요. 대상 Chrome 프로필과 확장이 맞는지 확인하고, 가져온 뒤 곡 개수·몇 줄의 원문과 번역·**교정 적용** 상태를 확인합니다.
- **LRC/SRT:** 같은 **가져오기** 버튼을 쓰지만, 선택한 곡의 편집 화면에 원문 줄을 넣는 동작입니다. 다른 곡에 덮어쓰지 않도록 대상 곡을 확인하고, 번역을 채운 뒤 **저장**합니다.

## 7. 문제가 생겼을 때

| 증상 | 먼저 확인할 것 |
| --- | --- |
| 확장 로드 오류 또는 이전 화면이 나옴 | `npm run build`가 완료됐는지, `dist`를 로드했는지 확인하세요. 확장 프로그램과 영상 탭을 둘 다 새로고침합니다. |
| 연결 테스트 오류 | Base URL, 모델 ID, 엔드포인트, 인증 방식, 접근 권한을 확인합니다. 401/403이면 키·계정 권한부터 확인하세요. |
| 테스트는 성공했는데 영상 자막이 안 나옴 | **설정 저장**, 팝업 **켜기**, 목표 언어, 실제 영상 재생을 확인합니다. 공식 자막 모드라면 제작자 원문 자막 트랙을 확인합니다. |
| 음성 자막이 안 나옴 | 본편 재생 중 해당 탭에서 **음성 시작**을 눌렀는지, 탭 캡처를 허용했는지 확인합니다. 로컬 STT는 서버 실행 후 **로컬 STT 연결 확인** 또는 `npm run stt:health`를 사용합니다. |
| 사전에서 저장이 막힘 | 일괄 편집 초안이 있으면 **일괄 반영** 후 **저장**합니다. |

## 8. 개인정보와 비용

- API 번역은 원문 자막 또는 STT 결과와 번역 문맥을 번역 제공자에 보냅니다. 클라우드 STT는 선택한 영상 탭의 오디오 조각도 STT 제공자에 보냅니다. 각 API에 별도 요금이 발생할 수 있고 공식 자막 선번역도 사용량에 포함됩니다.
- API 키는 Chrome의 로컬 확장 저장소에 저장됩니다. 키를 GitHub, 스크린샷, 로그에 넣지 마세요. 곡 교정 사전은 Chrome 프로필에 로컬 저장됩니다.
- **로컬 STT + LM Studio 또는 Ollama**를 선택하면 인식과 번역을 로컬에서 처리합니다. 모델 다운로드와 영상 재생에는 네트워크가 필요합니다. 가사 검색 보조를 켜면 제목·설명에서 뽑은 검색어가 LRCLIB에 전송되므로, 원하지 않으면 **전체 설정**에서 **제목·설명의 가사 검색으로 공식 자막 문맥 보조 + STT 보정**을 끄고 저장하세요.
