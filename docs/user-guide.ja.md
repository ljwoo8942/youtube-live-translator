# はじめて使う YouTube Live Translator

[한국어](user-guide.ko.md) · [English](user-guide.en.md) · [日本語](user-guide.ja.md)

[README に戻る](../README.md)

> 本拡張機能は、独立して開発された非公式のプロジェクトです。YouTube や NAVER CHZZK の公式サービスではなく、両サービスの運営元との提携関係はなく、公式な承認も受けていません。

YouTube や CHZZK（치지직）の動画に、翻訳字幕を重ねて表示する Chrome 拡張機能です。このガイドでは、まず YouTube の公式字幕を使って翻訳を試し、その後で音声認識の設定を説明します。

画面の項目名は韓国語です。以下では **`전체 설정`（すべての設定）** のように、実際の表示名と日本語の説明を並べています。

## 1. 用意するもの

- Windows、または macOS 14 以降の Apple Silicon（M シリーズ）Mac。Intel Mac は対象外です。
- パソコン版 Chrome 116 以降。
- Git と Node.js 22.18 以降。Node.js は 24 を推奨します。
- 翻訳に使う API サービスのキーと、そのキーで利用できるモデル名。外部 API は利用料金が発生する場合があります。

ローカル音声認識を使う場合だけ、追加で [uv](https://docs.astral.sh/uv/getting-started/installation/) が必要です。公式字幕の翻訳やクラウド API による音声認識だけなら、ローカル STT サーバーのインストールは不要です。

**対応サイトは YouTube と CHZZK です。** `m.youtube.com` もパソコン版 Chrome で開く場合の対応であり、スマートフォンの YouTube アプリやモバイルブラウザーには対応していません。他の動画サイトやパソコン内の動画ファイルも対象外です。

> STT は「音声を文字にする処理」です。「音声を文字にするサービス」と「その文字を翻訳するサービス」は別々に設定します。

## 2. インストールする

### ソースから拡張機能を作る

Windows では PowerShell、Mac ではターミナルを開き、保存先のフォルダーで次を順番に実行します。

```bash
git clone https://github.com/ljwoo8942/youtube-live-translator.git
cd youtube-live-translator
npm ci
npm run build
```

`npm ci` は必要なパッケージのインストール、`npm run build` は Chrome に読み込ませるファイルの作成です。成功すると、プロジェクト内に `dist` フォルダーができます。

### Chrome に読み込む

1. Chrome のアドレスバーに `chrome://extensions` と入力します。
2. 「デベロッパー モード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」を押します。韓国語の Chrome では `압축해제된 확장 프로그램을 로드합니다` と表示されます。
4. 作成された **`dist` フォルダー**を選びます。プロジェクト全体や ZIP ファイルではありません。
5. Chrome の拡張機能メニューから YouTube Live Translator を固定しておくと、設定を開きやすくなります。

読み込み後も `dist` フォルダーは削除・移動しないでください。

## 3. まずは YouTube の公式字幕で試す

最初は、投稿者が用意した原文の公式字幕がある動画を使います。YouTube の自動生成字幕や自動翻訳だけがある動画は、この手順の確認用には向きません。

1. YouTube で動画を開き、プレーヤーの字幕メニューから原文の公式字幕を選びます。
2. Chrome の拡張機能アイコンを押し、`전체 설정`（すべての設定）を開きます。
3. `확장프로그램 켜기`（拡張機能を有効にする）をオンにします。
4. `입력 방식`（入力方式）で `선택한 공식 자막만 사용 - STT/자동 자막 무시`（選んだ公式字幕のみ使用し、STT・自動字幕は使わない）を選びます。
5. `번역 provider`（翻訳サービス）を `AI API` にします。
6. `목표 언어`（翻訳先の言語）に `ja` を入力します。英語なら `en`、韓国語なら `ko` です。`음성 언어`（音声の言語）は翻訳先ではありません。
7. `AI API` セクションで API の接続情報を入力します。
   - OpenAI を使う場合は `API 프리셋` の `OpenAI 공식`（OpenAI 公式）を選び、`프리셋 적용`（プリセットを適用）を押します。
   - 別の OpenAI 互換サービスなら、そのサービスに合うプリセット、または `직접 입력`（手動入力）を選びます。Base URL・認証方式・モデルは利用するサービスの案内に合わせてください。
   - `API 키` に自分の API キーを入力し、`모델 목록 불러오기`（モデル一覧を取得）で取得した一覧から利用できるモデルを選びます。モデル名を直接指定する場合は、サービスが案内する正確な名前を使います。
8. `현재 설정 연결 테스트`（現在の設定で接続テスト）を押します。必要な場合は、Chrome が表示する指定 API サーバーへのアクセス許可を確認します。
9. 成功したら **`설정 저장`（設定を保存）**を押します。
10. 動画に戻り、字幕のある場面を再生します。動画の上に日本語の翻訳字幕が表示されれば、最初の設定は完了です。

**接続テストだけでは設定は保存されません。** テスト成功は API に接続できたことの確認であり、動画の字幕取得や音声キャプチャまで成功したことを意味するものではありません。

公式字幕のみのモードでは、ローカル STT を起動したり `음성 시작`（音声認識を開始）を押したりする必要はありません。全体設定の上部にローカル STT のおすすめが表示されても、この手順では設定しなくて大丈夫です。

## 4. CHZZK や公式字幕のない動画を翻訳する

この場合は、動画タブの音声を文字にしてから翻訳します。まずはローカルサーバーの不要な API 方式を紹介します。

### API で音声認識する

1. `전체 설정`（すべての設定）を開きます。
2. `API 키로 음성 자막 프리셋`（API キーで音声字幕を使うプリセット）を押します。
3. 翻訳用の `AI API` と、音声認識用の `API STT` の接続情報を確認します。API STT の初期値は次のとおりです。
   - Base URL: `https://api.openai.com/v1`
   - エンドポイント: `/audio/transcriptions`
   - モデル: `gpt-4o-mini-transcribe`
   - 認証: `Authorization: Bearer`
4. `API STT` の `API 키` に、音声認識サービスで利用できるキーを入力します。
5. `목표 언어`（翻訳先の言語）を確認します。日本語なら `ja` です。
6. `API STT + 번역 연결 테스트`（API 音声認識と翻訳の接続テスト）を押し、結果を確認してから `설정 저장`（設定を保存）を押します。
7. 動画タブに戻って本編を再生します。拡張機能のポップアップを開き、`음성 시작`（音声認識を開始）を押します。Chrome がタブの音声キャプチャ権限を求めた場合は内容を確認して許可します。
8. 終了するときは `음성 중지`（音声認識を停止）を押します。

`API STT` のキーが空欄だと `AI API` のキーが音声認識にも使われます。しかし、**翻訳用のキーがどの音声認識サービスでも使えるわけではありません。** 翻訳と音声認識でサービスが異なる場合は、それぞれに対応するキーと URL を入力してください。

`선택한 공식 자막 우선 + 없으면 음성`（公式字幕を優先し、なければ音声）では、YouTube は公式字幕を優先し、CHZZK はタブ音声を使います。音声だけで試したい場合は、全体設定の `음성만 - YouTube 자막/자동 번역 무시`（音声のみ使用）を選んで保存します。ポップアップでは音声のみの選択肢が `음성만 - 탭 음성 인식` と表示されます。

YouTube で `음성 시작` を押すと入力方式が音声のみになります。公式字幕に戻すときは、全体設定で公式字幕のみを選び直して保存します。

音声認識では処理時間がかかるため、発話と同時に字幕が出るわけではありません。歌声・雑音・複数人の会話では、誤認識や字幕が出ない区間が生じることもあります。

### 任意：パソコン内で音声認識する

外部に音声を送らずに認識したい場合は、付属のローカル STT を使えます。翻訳に `AI API` を選ぶ場合、**認識後の文字は翻訳サービスに送信されます。**

uv をインストールしたうえで、プロジェクトのフォルダーから実行します。

```bash
npm run stt:setup
npm run stt:start
```

このターミナルは使用中ずっと開いておきます。初回はモデルのダウンロードに時間がかかることがあります。別のターミナルを同じフォルダーで開き、次のコマンドで状態を確認できます。

```bash
npm run stt:health
```

続いて全体設定で次を行います。

1. 翻訳用の `AI API` を設定します。
2. `로컬 STT + 번역 API 프리셋`（ローカル音声認識＋翻訳 API のプリセット）を押します。
3. `로컬 STT 연결 확인`（ローカル STT の接続確認）を押します。
4. `로컬 STT + 번역 연결 테스트`（ローカル STT と翻訳の接続テスト）を行い、`설정 저장`（設定を保存）を押します。
5. 動画タブで `음성 시작`（音声認識を開始）を押します。

最初は Whisper の既定モデル `small` で試してください。M シリーズ Mac は MLX、Windows は利用できる NVIDIA GPU があれば CUDA、なければ CPU を使います。Windows の仮想環境 `.venv-stt` を Mac にコピーせず、使うパソコンごとにセットアップしてください。

ポップアップの `로컬 STT 시작`（ローカル STT を起動）は、別途 Chrome Native Messaging の登録を済ませた場合に使う機能です。上のターミナル方式では登録は不要です。Qwen の準備、モデル変更、ポップアップからの起動、Ollama の設定は詳細ガイドを参照してください。[詳細ガイド（韓国語）](advanced-guide.ko.md)

音声認識と翻訳をパソコン内で行うには、LM Studio を介して Gemma 4 を接続します。テンポの速い日本語曲で検証した Qwen 1.7B と 14 秒の HTTP 音声認識の設定も掲載しています。[LM Studio 設定ガイド](lm-studio-settings.ja.md)

## 5. 毎日の操作と字幕の調整

- ポップアップの `전체 설정` は設定画面、`교정 사전` は曲の補正辞書を開きます。
- `입력·언어·모델 설정`（入力・言語・モデルの設定）を展開すると、ポップアップでも入力方式や翻訳先などを変更できます。変更後は `저장`（保存）を押します。
- `영상 미니 컨트롤`（動画内のミニコントロール）をオンにすると、プレーヤー上で字幕のオン／オフ、原文の表示、文字サイズ、位置などを調整できます。
- 全体設定の `오버레이`（字幕の重ね表示）でも見た目を調整できます。
- 歌詞として翻訳したいときは `콘텐츠 모드`（コンテンツの種類）の `노래/가사`（歌・歌詞）を選びます。会話中心なら `일반 영상`（一般の動画）、配信なら `라이브/잡음`（ライブ・雑音）も選べます。

## 6. 曲の補正辞書を使う

よく聴く曲の誤訳を、自分で用意した訳文に置き換えられます。全体設定の `곡 교정 사전`、またはポップアップの `교정 사전` から開きます。

1. `새 곡`（新しい曲）を押します。
2. `곡 이름`（曲名）、`가수/아티스트`（歌手・アーティスト）、必要に応じて `YouTube 영상 ID`（動画 ID）を入力します。`현재 영상 가져오기`（現在の動画情報を取得）も使えます。
3. `원문 언어`（原文の言語）と `목표 언어`（訳文の言語）を確認します。日本語の訳文なら、目標言語は `ja` です。
4. `원문`（原文）と `교정 번역`（補正する訳文）を対応する行に入力します。
5. 一括入力した場合は **`일괄 반영`（一括入力を反映）を押してから `저장`（保存）**を押します。
6. ポップアップの `사용자 교정 사전`（ユーザー補正辞書）をオンにして使います。

公式字幕では保存した原文に一致する行を補正します。音声認識では同じ曲の原文と 2 行連続で一致した後に補正を使うため、保存直後のすべての発話が必ず置き換わるわけではありません。

### バックアップとファイルの読み込み

- `내보내기`（書き出し）で JSON バックアップを保存できます。
- `가져오기`（読み込み）で JSON を選ぶと、確認後に**現在保存されている曲の一覧を置き換えます。追加ではありません。** 空の曲リストを読み込むと全曲が消えます。先に現在の辞書を書き出しておきましょう。
- SRT・LRC を読み込むと、編集中の曲の原文行に読み込まれます。これは保存済みの完成した辞書ではなく、編集用の下書きです。内容と訳文を確認してから `저장` を押してください。
- 未保存の変更を破棄する確認が出た場合、残しておきたい変更があればキャンセルして先に保存します。

## 7. 更新する

必要なら、まず曲の補正辞書を JSON に書き出します。ソースを自分で変更している場合は、その変更も保管してください。プロジェクトのフォルダーで実行します。

```bash
git pull
npm ci
npm run build
```

その後、次の **両方** を行います。

1. `chrome://extensions` で拡張機能を再読み込みします。
2. 開いていた YouTube・CHZZK の動画タブも再読み込みします。

ローカル STT を使っている場合は、実行中のサーバーを終了してから次を実行します。ターミナルから起動していたサーバーは、そのターミナルで Ctrl+C を押して停止できます。

```bash
npm run stt:setup
npm run stt:start
```

`git pull` がローカル変更との競合で止まった場合は、ファイルを強制的に削除・上書きせず、変更内容を確認してください。

## 8. うまく動かないとき

| 症状 | 確認すること |
| --- | --- |
| `git` や `npm` が見つからない | Git・Node.js をインストールしたか確認し、ターミナルを開き直します。Node.js は 22.18 以降が必要です。 |
| Chrome に読み込めない | ビルドが成功したか、選んだフォルダーが `dist` かを確認します。 |
| 更新しても画面が変わらない | ビルド後、拡張機能と動画タブの両方を再読み込みします。 |
| ボタンが使えない | YouTube または CHZZK の再生タブでポップアップを開き直します。 |
| 接続テストは成功したのに字幕が出ない | 設定を保存したか、拡張機能がオンか、入力方式が正しいか、動画が再生中かを確認します。公式字幕のみの設定なら、原文の公式字幕が必要です。 |
| 音声字幕が出ない | 本編を再生し、`음성 시작` を押したか、タブキャプチャが許可されているかを確認します。 |
| API が 401 / 403 を返す | キー、利用可能なモデル、API の権限、URL、認証方式を確認します。翻訳用と音声認識用のキーを取り違えていないかも確認します。 |
| ローカル STT に接続できない | サーバーのターミナルが開いているか確認し、`npm run stt:health` で状態を確認します。 |
| Chrome 連携プログラムの登録を求められる | ポップアップからのサーバー起動には Native Messaging の登録が必要です。先にターミナルから `npm run stt:start` を使うこともできます。 |
| 選択したモデルが準備されていない | ダウンロード済みのモデルを選ぶか、詳細ガイドのモデル準備手順を行います。モデルの選択後は設定を保存します。 |
| 辞書の一括編集後に保存できない | `일괄 반영` で入力を反映してから保存します。 |

エラーを相談するときは、操作した手順と表示されたエラー文を伝えてください。API キーが写った画面や認証情報は共有しないでください。

## 9. プライバシーと料金

- API キーは Chrome プロファイル内の `chrome.storage.local` に保存されます。リポジトリやビルド済み拡張機能にキーを埋め込む必要はありません。
- 外部の翻訳 API を選ぶと、原文字幕・音声認識した文字・翻訳の文脈が設定したサービスに送られます。
- クラウド STT を選ぶと、選択した動画タブの音声データも STT サービスに送られます。
- ローカル STT と LM Studio・Ollama による翻訳を組み合わせれば、音声認識と翻訳の計算をパソコン内で行えます。ただし、動画再生や最初のモデルダウンロードにはネットワーク接続が必要です。
- `자막 없는 노래에서 제목·설명의 가사 후보로 STT 보정`（字幕のない曲で、タイトル・説明から得た歌詞候補を使って STT を補正）をオンにすると、動画のタイトル・説明から抽出した検索語が LRCLIB に送られます。必要なければオフにできます。
- 曲の補正辞書はブラウザー内の IndexedDB に保存され、辞書全体をサーバーへ送信する仕組みではありません。パソコンや Chrome プロファイルを移すときは JSON バックアップを使ってください。
- API の接続テストや字幕翻訳、音声認識には、サービス側の利用料金が発生する場合があります。公式字幕は先の部分を先行翻訳することもあります。先行翻訳の処理件数制限は、請求額全体の上限ではありません。サービス側の使用量・予算設定も確認してください。

より詳しい設定は [詳細ガイド（韓国語）](advanced-guide.ko.md)、対応範囲や技術情報は [README](../README.md) を参照してください。
