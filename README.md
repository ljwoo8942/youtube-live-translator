# YouTube Live Translator

YouTube와 치지직의 라이브·다시보기에 번역 자막을 표시하는 Chrome 확장 프로그램입니다.

A Chrome extension that displays translated subtitles on YouTube and CHZZK, for both live streams and replays.

YouTube と CHZZK のライブ配信・アーカイブに翻訳字幕を表示する Chrome 拡張機能です。

> 이 확장 프로그램은 독립적으로 개발된 비공식 프로젝트입니다. YouTube 또는 네이버 치지직(CHZZK)의 공식 서비스가 아니며, 두 서비스의 운영사와 제휴 관계가 없고 공식 승인이나 보증을 받지 않았습니다.
>
> This is an independent, unofficial Chrome extension. It is not an official service of YouTube or NAVER CHZZK and is not affiliated with or endorsed by either platform.
>
> 本拡張機能は、独立して開発された非公式のプロジェクトです。YouTube や NAVER CHZZK の公式サービスではなく、両サービスの運営元との提携関係はなく、公式な承認も受けていません。

## 사용 설명서 · User guide · ユーザーガイド

**[한국어](docs/user-guide.ko.md) · [English](docs/user-guide.en.md) · [日本語](docs/user-guide.ja.md)**

- 처음이라면 사용 설명서에서 공식 자막이 있는 YouTube 영상부터 시작하세요. 치지직과 공식 자막이 없는 영상은 음성 인식 설정이 필요합니다.
- New here? Start with a YouTube video that has creator-provided captions. CHZZK and videos without those captions need speech recognition.
- 初めての方は、投稿者が用意した字幕のある YouTube 動画からお試しください。CHZZK や投稿者による字幕がない動画には、音声認識の設定が必要です。
